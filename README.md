<h2> Funções para leitura de arquivo externo e escrita de arquivo externo. É utilizado um arquivo de entrada e um de saída, ambos passados pelo terminal de comando. </h2>

<h3> Binário </h3>
<h2> Não é possível ler um arquivo binário a "olho nu"</h2>
<p> 
  Para eu conseguir um arquivo binário, é necessário utilizar a função contida em gerarArqBinario.c. É preciso dar um "arquivoEntrada.bin"
  Após gerar esse arquivo, utilizo a função contida em leituraBinaria.c para fazer minhas modificações, que resultarão em um outro arquivo binário 
</p>

<h3> Normal </h3>
<p> 
  Ler um arquivo de entrada .txt e devolver um arquivo de saída .txt
</p>
